# CodeAlpha Stock Portfolio Tracker

## Description
A simple stock portfolio tracker developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Uses a hardcoded stock-price dictionary
- Accepts stock names from the user
- Accepts stock quantities
- Calculates individual investment value
- Calculates total investment value
- Handles invalid stock names
- Displays a portfolio summary
- Saves the portfolio result to a text file

## Technologies Used
- Python

## Concepts Used
- Dictionaries
- User input and output
- Basic arithmetic
- While loops
- If-else statements
- File handling

## How to Run
Run the Python program and enter the stock name and quantity when prompted.
Type `done` when you have finished entering stocks.
